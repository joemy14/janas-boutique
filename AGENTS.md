# Instructions for coding agents

- Read `README.md` and `docs/handoff.md` before making changes.
- Keep replies short and use clear steps.
- Never commit `frontend/.env.local`, passwords, or database credentials.
- Change one file at a time, and briefly say what changed.
- Use `backend/db.php` for database access. Do not create another `mysqli` connection.
- Verify changes before saying they work. State what you checked and any remaining limitation.
